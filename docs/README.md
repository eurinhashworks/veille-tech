## À propos

TechPulse AI est une application web moderne qui utilise l'API Google Gemini pour générer automatiquement des revues technologiques quotidiennes. Elle agrège les dernières actualités en développement web, cloud computing, DevOps, cybersécurité et intelligence artificielle.

**Technologies utilisées :**
- React 19
- TypeScript
- Vite
- Google Gemini AI
- Tailwind CSS (via classes utilitaires)
